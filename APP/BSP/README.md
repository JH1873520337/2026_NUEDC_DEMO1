# BSP 板级支持层规范

## 定位

`BSP`（Board Support Package）负责板级外设和板载芯片驱动，为上层提供与具体引脚、总线实例和 HAL 句柄解耦的稳定接口。

典型模块包括 IMU、编码器、电机驱动、屏幕、存储器，以及对 SPI、I2C、UART、ADC、PWM 等板级资源的封装。

## 依赖边界

```text
Serves
   |
   v
  BSP -> Core / STM32 HAL / LL
```

- 可以依赖 `Core/Inc`、`Drivers` 和 CubeMX 生成的外设句柄。
- 不得依赖 `Serves`、`Algorithm` 或 `Task`。
- 不包含业务流程、任务调度和算法决策。
- 原则上不直接依赖 FreeRTOS；并发保护、重试和调度由服务层负责。
- 禁止在 BSP 中创建任务、队列、信号量或执行无限循环。

## 目录要求

每个芯片或独立板级外设必须建立单独文件夹，不允许把多个驱动的 `.c/.h` 文件直接堆放在 `BSP` 根目录。

每个驱动目录至少包含以下三个文件：

```text
BSP/
  ICM42588/
    ICM42588.c
    ICM42588.h
    README.md
  W25Q128/
    W25Q128.c
    W25Q128.h
    README.md
```

- 文件夹名直接使用芯片完整型号，例如 `ICM42588`。
- `.c` 和 `.h` 的主文件名必须与文件夹名完全一致，包括字母和数字。
- 扩展名统一使用小写 `.c`、`.h`；芯片型号部分保持数据手册中的标准大写形式。
- 没有明确芯片型号的板级功能仍需独立目录，可使用 `LED`、`KEY`、`BUZZER` 等明确名称。
- 一个目录只实现一个芯片或一个独立板级功能，禁止混入上层业务代码。

## 驱动 README 要求

每个芯片目录中的 `README.md` 必须至少说明：

- 芯片完整型号、用途和所依据的数据手册版本。
- 与 STM32 的连接关系，包括总线实例、地址/片选、中断和复位引脚。
- CubeMX 中需要启用的外设、DMA、中断及关键参数。
- 初始化流程、主要公共接口和最小调用示例。
- 数据单位、量程、坐标系、字节序及关键寄存器配置。
- 阻塞时间、超时、线程安全和中断上下文限制。
- 已知问题、调试方法和硬件注意事项。

README 中不得保存密钥、设备唯一凭据或仅适用于个人电脑的绝对路径。

## 命名规范

- 公共类型和函数直接使用芯片型号作为前缀，例如 `ICM42588_Init()`、`ICM42588_Read()`。
- 类型名使用芯片型号前缀和 `_t` 后缀，例如 `ICM42588_Data_t`、`ICM42588_Status_t`。
- 寄存器和位定义使用全大写前缀，例如 `ICM42588_REG_WHO_AM_I`。
- 私有函数和私有变量使用 `static`。
- 公共头文件只暴露必要类型、状态码和接口，不暴露内部 HAL 实现细节。
- 头文件保护宏使用 `<CHIP>_H`，例如 `ICM42588_H`。

## 接口规范

- 初始化函数必须返回明确状态，禁止静默忽略 HAL 错误。
- 阻塞接口必须有超时参数或明确、可接受的最坏执行时间。
- 对 DMA/中断接口明确缓冲区所有权、忙状态和完成回调的执行上下文。
- 中断回调只完成清标志、记录数据或通知上层等短操作，不做阻塞处理。
- 不在驱动内部使用无界重试、长时间延时或动态内存分配。
- 多实例器件优先使用上下文结构体，避免不可扩展的全局单例。

## 推荐接口示例

```c
typedef enum {
    ICM42588_OK = 0,
    ICM42588_ERROR,
    ICM42588_BUSY,
    ICM42588_TIMEOUT
} ICM42588_Status_t;

ICM42588_Status_t ICM42588_Init(void);
ICM42588_Status_t ICM42588_Read(ICM42588_Data_t *data,
                                uint32_t timeout_ms);
```

## CMake 接入

新增驱动后，需要把源文件和芯片目录加入根 `CMakeLists.txt`：

```cmake
target_sources(${CMAKE_PROJECT_NAME} PRIVATE
    APP/BSP/ICM42588/ICM42588.c
)

target_include_directories(${CMAKE_PROJECT_NAME} PRIVATE
    APP/BSP/ICM42588
)
```

## 提交前检查

- 驱动拥有独立目录，且 `.c`、`.h`、`README.md` 三个文件齐全。
- 目录、文件、类型、函数和宏使用同一个芯片型号。
- 引脚、总线、地址和量程等硬件参数有唯一配置入口。
- 所有 HAL 返回值均已处理。
- ISR 与任务上下文共享数据使用了正确的 `volatile`、临界区或上层同步机制。
- 新增源文件和包含目录已加入根 `CMakeLists.txt`。
- 关键接口具备可在无业务逻辑条件下独立验证的方法。
